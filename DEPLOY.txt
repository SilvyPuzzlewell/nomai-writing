Nomai Thread Viewer - Fly.io Deployment Instructions
====================================================

PREREQUISITES
-------------
- Fly.io account (free at https://fly.io)
- Fly CLI installed

INSTALL FLY CLI
---------------
curl -L https://fly.io/install.sh | sh

FIRST-TIME DEPLOYMENT
---------------------
1. Login to Fly.io:
   fly auth login

2. Launch the app (creates app config, don't deploy yet):
   fly launch --no-deploy

3. Create persistent volume for SQLite database:
   fly volumes create nomai_data --size 1 --region iad

4. Deploy the app:
   fly deploy

5. Open in browser:
   fly open

SUBSEQUENT DEPLOYMENTS
----------------------
Just run:
   fly deploy

USEFUL COMMANDS
---------------
- View logs:        fly logs
- SSH into app:     fly ssh console
- Check status:     fly status
- View app URL:     fly open
- Scale memory:     fly scale memory 512
- View volumes:     fly volumes list

LOCAL DEVELOPMENT
-----------------
Run locally with:
   ./run.sh

Then open http://localhost:5000

CONFIGURATION
-------------
- App name is set in fly.toml (default: nomai-threads)
- Database is stored in /data/threads.db (persistent volume)
- Region can be changed in fly.toml (default: iad = Virginia)

TROUBLESHOOTING
---------------
- If volume not found: fly volumes create nomai_data --size 1 --region <your-region>
- If app crashes: fly logs --app nomai-threads
- If database empty: Data persists in volume; check volume is mounted
